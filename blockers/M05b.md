# M05b — Mid-flight rendering and throughput

Status: open. Full verification exits 1; do not publish as verified.

## Evidence

Final configured `npm run verify`: typecheck, lint, placeholders and unit pass; `Test Files 52 passed (52)`, `Tests 370 passed (370)`, Playwright `1 failed`, `46 passed (16.6m)`. The sole failure is the unchanged M04b mid-flight screenshot at `tests/e2e/m04.spec.ts:350`: `assertNotBlank failed: 100% of pixels are blank color`. The image was opened and is uniformly blue.

The master baseline also fails this same nonblank assertion in this environment (`work/master-baseline.log`: 5 passed / 1 failed). This does not establish that the branch matches master's performance: generated/lit/meshed/uploaded columns per second are master 33.1853 / 0.0000 / 14.3164 / 14.2305 and branch 29.6420 / 24.8511 / 8.3008 / 7.7372. Master has no streamed-light stage. Final branch main-thread light copy/commit mean/p95/max is 1.1450 / 1.3000 / 38.2000 ms. Strict smooth-light/AO merging increases spawn triangles from 272,740 to 536,988 (+96.8864%).

## Approaches tried

- Reduced mesh-worker input overhead by transferring padded snapshots, shared corner sample stencils, and a sky-only shader variant for zero-RGB sections. The full run still produced a blank mid-flight image and timed out waiting for heap-test streaming idle.
- Improved stage scheduling: distance priority for deferred uploads, resume mesh dispatch immediately when upload backpressure clears, and batch ready lighting strips along either horizontal axis. The unchanged mid-flight check still failed; measured throughput stayed below master.
- Removed regular-upload wireframe work: outline index buffers are now built and uploaded only when wireframe is first drawn. The unchanged wireframe check passed. A complete targeted M04 run passed flight/culling, heap and horizon but still failed mid-flight (5 passed / 1 failed). The final full run confirms the same remaining failure.

Separately, fixed a proven debug-light redraw bug and an unlit-border edit snapshot race in source. Their regression checks pass, as do both M03 cave checks in the final full run. No legacy assertion, threshold, expected value, timeout or case was changed. The only greedy/model test changes decode through the shared source decoder; both pass.

## Current direction

The owner has explicitly directed continued profiling in this environment. The same-environment master comparison is valid and the branch regression is real. No alternative-environment baseline is planned. Target: mesh/upload throughput at least 90% of master (at least 13 columns/s), visible sections at least 90% of master (about 165), and cancels no higher than master. Re-check M05 criteria after every behavioral change. Split/time-slice main-thread light work to keep it within an 8 ms frame budget.

Worker instrumentation shows substantial delays between completed mesh computation and main-thread result handling. Bounded posted jobs and batched result delivery are being evaluated without reducing light quality, AO, merge strictness or legacy criteria. The blocker remains open until the targets and the required verification are met.
