## What was built

- **Procedural Cloud Generator & Renderer (`src/render/clouds.ts`):**
  - Seeded 32×32 periodic cellular noise grid generator with octaves, generating smooth clustered cloud patches with exactly ~35% active coverage (358 active cells out of 1024).
  - Extruded 3D volumes (4 blocks thick, y=192..196) with face culling between adjacent cells, directional face shading (`top = 1.0`, `side = 0.85`, `bottom = 0.70`), and distance fog fade into view-dependent `skyAtmosphereColor`.
  - Fast 2D flat textured plane at y=192 using a 32×32 nearest-neighbor repeating texture generated directly from the noise grid.
  - Wind drift advancing smoothly along +X at 1.0 block/s derived from `worldTime / 20.0`.
  - Region instancing (3×3 grid of 384-block regions) with distance culling against `fogEnd = Math.max(140, (renderDistance - 1) * 16)`.
  - Static GPU VBO/VAO buffers created at init time; zero per-frame buffer allocations.
  - Modulated by time-of-day sky brightness (`skyLightMultiplier`) and fog color.
- **Engine Settings & Debug API (`src/engine/settings.ts`, `src/debug/api/clouds.ts`, `src/debug/api/core.ts`, `src/debug/api/index.ts`):**
  - Added `clouds: 'fancy' | 'fast' | 'off'` (default `'fancy'`) to engine settings.
  - Added `setClouds(mode)` to the debug API in `src/debug/api/clouds.ts` and registered it in `src/debug/api/index.ts`.
- **Sun Glare in Sky Shader (`src/render/sky.ts`):**
  - Height-dependent sun glare calculated in `SKY_FS` based on view ray alignment with `u_sunDir` and sun altitude `u_sunDir.y`.
  - High sun: large radius (0.28), intense brightness (1.45), saturating to pure white `(1.0, 1.0, 1.0)`, with sun billboard alpha faded to 0 to wash out the pixel disc.
  - Low sun (sunset/sunrise): shrunken radius (0.12), dimmed intensity (0.40), warm amber tint `(1.0, 0.55, 0.15)`, and sun billboard alpha restored (`0.818`) so the pixel disc is crisp and legible.
- **WorldManager Integration (`src/world/world-manager.ts`):**
  - Instantiates `CloudRenderer` with `gl` context.
  - Invokes `cloudRenderer.render(...)` after terrain quads and before cross-mesh items.
  - Tracks cloud draw calls and triangle counts in `renderStats`.
