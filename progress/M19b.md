## What was built

- Registered four original house templates, an irrigated crop farm, a well with a seeded chest, a
  ladder lookout, and surface-following path pieces through the M19a jigsaw pipeline. Placement
  data remains `wayfarer_hamlet` spacing 34 / separation 16.
- Added static `farmland` and `wheat_crop` with eight age states, cutout cross rendering, seeded
  palette-limited generators, item icons, and block loot. No growth, hoe, or tilling behavior was
  added. New state IDs are appended after 810: farmland 811, wheat ages 0–7 are 812–819.
- Added `data/loot/chests/wayfarer_hamlet.json`, loaded through `src/gameplay/chest-loot.ts`; the
  block-loot loader's unit test confirms it ignores nested chest tables.
- Preserved damage and affixes through item drops, pickup, chest break, kiln spill, and
  serialization. Variant stacks do not merge with different variants.
- Passed the Create World Structures option into generation. Disabled workers use an empty
  structure pipeline. Added debug-only locate and M13b pathfinding wrappers without changing
  `World` or its hot shared objects.
- Kept structure work in the generation stage: it samples surfaces and assembles templates only
  for eligible nearby starts, uses a bounded start cache, and scans only generated sections that
  contain chest blocks for block-entity setup. No per-frame or per-tick work was added.
