## What was built

- Extended `src/engine/settings.ts` with the complete M18 settings model and defaults that preserve current behavior, including render distance 8, FOV 70°, fancy leaves/clouds, smooth lighting and particles on, automatic GUI scale, brightness and volumes at 100%, and view bobbing on.
- Added `src/engine/keybinds.ts` as the shared action-to-key map for gameplay, HUD, menus and remapping. Conflicts are detected, displayed, and route the shared key to each bound action.
- Added `src/ui/settings-screen.ts`, a pixel-font overlay with video, audio and keybinding tabs, slider/toggle controls, reset and done buttons, mouse and keyboard remapping, and a visible conflict warning. Main-menu and pause-menu entry points were added with small changes to `src/ui/main-menu.ts` and `src/ui/ui-manager.ts`.
- Added settings persistence through IndexedDB in `src/engine/settings-persistence.ts`; `src/persist/idb.ts` moves to DB version 2 and creates the settings store while preserving existing world stores and records. Settings load and apply before the main menu appears; missing, invalid and unreadable settings fall back to defaults.
- Applied settings through current game paths for render distance, FOV, camera sensitivity and Y inversion, leaves, clouds, smooth lighting, particles, GUI scale, brightness and view bobbing. The existing synthesized sound effects apply master × effects volume. Music and ambient levels are stored; M16b wires the full volume model and separate playback categories.
- Added the `src/debug/api/settings.ts` read/set/reset API and registered it in `src/debug/api/index.ts`.

## Notes for dependent tasks

- Use `settings` from `src/engine/settings.ts` for live values and `src/engine/keybinds.ts` for action codes. All input readers should use this map so remaps take effect immediately.
- `src/engine/settings-runtime.ts` applies user changes to existing engine paths and persists them; use `setSetting` or the debug API instead of mutating values directly when a change should be applied and saved.
- Settings use IndexedDB store `settings`, record key `global`. World-specific copy, rename and delete continue to operate only on `WORLD_STORE_NAMES`.
- GUI scale changes dispatch `GUI_SCALE_CHANGE_EVENT`; cached HUD content invalidates only when the chosen scale changes.
