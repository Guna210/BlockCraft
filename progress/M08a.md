## Notes for dependent tasks

- Fluid states use strings (`level: '0'`–`'7'`, `falling: 'false' | 'true'`) to match the existing enum registry. Source means level zero and falling false. All lava states share emission 15.
- `data/block-state-ids.json` is append-only. It pins legacy source IDs (lava and water) and every other old palette ID, then appends new states. Add new persistent states after its maximum; do not renumber entries. Unrecorded states still allocate deterministically above the recorded maximum.
- `World.ticks` is a `BlockTicks` instance. Schedule `{x,y,z,type}` with a positive delay and optional numeric priority (lower runs first); repeated position/type notifications coalesce. `advance` dispatches in due/priority/insertion order. `World.tick` is called only from the shared game-loop simulation callback in normal gameplay.
- Register random work with `ticks.setRandomTicks(sectionSupplier, samplesPerSection, seed, visitor)`. Supply `() => world.getTickSections()` for allocated loaded sections and the world seed. It samples with replacement, after scheduled dispatch, independently for each section/tick. With no registration there is no section scan.
- `Streamer.canSimulate(cx, cz)` waits for first complete presentation, then permits physics through lighting/re-mesh refreshes while collision data remains loaded. It also handles completely empty columns; mesh eviction, stale discarded meshes and reset clear readiness. `src/main.ts` uses this instead of requiring the current phase to be meshed. `tests/unit/m08a-streaming-physics.test.ts` owns the regression; all earlier specs remain unchanged.
- Fluid changes use `World.setBlock` / `setBlockStateId`, preserving lighting and WorldManager's existing re-mesh invalidation. Future saving can subscribe to the same normal edit path. Generation should continue writing directly to columns, retaining zero fluid scheduling.
- M08b can read the state properties for surface heights and falling-column rendering. M09b owns Blackglass inventory icon UI. No rendering or weather interface is changed here.
