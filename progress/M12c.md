## What was built

- `src/world/weather.ts`: Weather state manager (`clear`, `rain`, `thunder`), precipitation type evaluator (`getPrecipitationType`), `WeatherHeightmap` tracking top solid elevations around the player, lightning trigger and seeded strike simulation, and budgeted deterministic accumulation tick.
- `src/debug/api/weather.ts` & `src/debug/api/index.ts`: Debug API `setWeather('clear' | 'rain' | 'thunder')` registered with one line.
- `src/debug/api/core.ts`: Debug API types and `getRenderStats().weather` schema with `state` and `activeParticles` counts.
- `src/render/weather.ts`: Full GPU-instanced precipitation particle renderer (static VBO instance data animated by `u_time`), surface splashes, procedural branching ribbon lightning generator (`generateLightningBolt`), and fast CPU particle count evaluation for render stats.
- `src/render/sky.ts`: Rain darkening, desaturation (`u_rainFactor`), and sky lightning flash (`u_lightningFlash`) in atmosphere shader.
- `src/render/chunk-renderer.ts`: Puddle darkening (`v_puddle`) on outdoor top solid faces during rain; rain fog darkening and desaturation; lightning flash uniform.
- `src/render/clouds.ts`: Cloud darkening, desaturation, and lightning flash uniforms.
- `src/world/world-manager.ts`: Integrated `WeatherRenderer`, heightmap updates on chunk load and block edit, weather accumulation in frame tick, and weather render stats.
- `data/blocks/weather.json` & `data/items/weather.json`: Added `ice` (translucent), `snow_layer` (slab), and `fire` (cutout cross) definitions and block items.
- `src/world/blocks/registry.ts`: Registered `fire` sorted as `foundation_stone_fire` to maintain stable IDs 0..28.
- `src/render/textures/weather.ts` & `src/render/textures/index.ts`: Deterministic procedural texture generators and palettes (`genIce`, `PAL_ICE`, `genFire`, `PAL_FIRE`) adhering to `ART.md`.

## Changes made on top of agy/m12c

- `WeatherManager.tick` now advances by game ticks elapsed (it used to run once per rendered frame); natural weather schedule after 12000 simulated ticks.
- Freezing used `World.getHeight`, which skips water, so water never froze; now uses the true surface. Snow no longer lands on cross plants or fire.
- Lightning flash additive reduced from 0.9 to 0.35 so a strike no longer whites out the sky (the old storm screenshot was a white sky).
- New `tests/unit/m12c-weather-sim.test.ts` (schedule, pause, strike, fire ignition, snow build-up, freezing, setBlock path).

## Known limitations

- The storm screenshot shows no lightning bolt; bolt rendering has unit coverage for generation only, not a pixel test.
- Puddle darkening and splashes have no dedicated automated test; they are exercised only by the rain e2e run.
- Known slow-container failure in this session: m02:54 mesh p95.

## Notes for dependent tasks

- `setWeather` is available on `window.__blockcraft.setWeather('clear' | 'rain' | 'thunder')`.
- `renderStats.weather` provides `{ state: WeatherState, activeParticles: { rain: number, snow: number } }`.
- Rain and snow particles wrap in a 32×24×32 box around camera position and are blocked below the top solid heightmap elevation.
