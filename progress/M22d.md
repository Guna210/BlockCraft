## What was built

Added the `subtitles`, `reducedMotion`, and `highContrast` settings with persistence, an ACCESS tab, live palette updates, camera-relative sound captions, and reduced-motion suppression for bobbing, explosion shake, sprint FOV, and low-health heart jiggle. Added high-contrast UI tokens, opaque caption and chat backing, and 7:1 contrast coverage. The global recovery handler catches render, browser error, and rejection faults once, saves singleplayer worlds with a 10-second limit, disconnects multiplayer without a local save, and provides a Back to title recovery action. Debug fault injection is available only in `?debug=1`.

Fixed the M16b-owned `AudioService` G12 clamping bug: listener position/orientation values retain negative components, and only gain values are clamped.

## Notes for dependent tasks

- Captions are read from `src/audio/captions.ts`; `getSubtitles()` returns text, optional direction, and age in milliseconds.
- The error boundary stops the next animation frame and singleplayer recovery saves through `SaveManager.exit()`. Multiplayer recovery calls `remoteExit()` and skips local persistence.
- The audio listener helper now accepts signed coordinates. This changes M16b-owned code and is covered by a unit test.
