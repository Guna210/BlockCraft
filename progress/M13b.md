## What was built

A high-performance 3D A* pathfinding module (`src/entity/ai/pathfinding.ts`) operating over a voxel grid through a minimal `WorldQuery` interface and `WorldAdapter`. It features:
- Pre-allocated TypedArray structures (`NodePool`, `CoordMap`, `MinHeap`) guaranteeing zero heap allocation per expanded node during search.
- An admissible Manhattan distance heuristic ensuring provable optimality without reopening closed nodes.
- Full 3D voxel movement graph: 4-directional walking, 1-block jumps with head clearance checks, controlled falls/drops of 1 to 3 blocks, cliff avoidance for drops $\ge 4$, and water swimming (horizontal, vertical up/down, entering water, and bank exit).
- Support for entity height clearance (1 or 2 blocks).
- Multi-tier block classification (`passable`, `solid`, `water`, `forbidden`) with a dynamic door predicate hook.
- A path caching layer keyed on `start`, `goal`, and `height`, invalidated by world edit version counters.
- An incremental search API with a per-tick expansion budget (`maxNodesPerTick`) as well as synchronous `findPath`.

## Known limitations

- Only 4-directional horizontal movement is used (no diagonals), completely avoiding corner-cutting issues and keeping the branching factor small for sub-millisecond execution.
- Wall climbing (Skitterer-specific in M13f) and flying pathfinding (Glowwing-specific in M20c) will build on or specialize this foundation in their respective tasks.

## Notes for dependent tasks

- **Module path:** `src/entity/ai/pathfinding.ts`.
- **Primary class:** `Pathfinder(world: WorldQuery, classifier?: BlockClassifier)`.
- **Synchronous API:** `findPath(start: BlockPos, goal: BlockPos, options?: PathOptions): PathResult`.
  - Returns `{ status: 'success' | 'unreachable', path: BlockPos[] | null, cost: number, nodesExpanded: number }`.
  - Coordinates are integer voxel arrays `[x, y, z]`.
- **Incremental API:** `createSearch(start: BlockPos, goal: BlockPos, options?: PathOptions): PathSearch`.
  - Call `search.step(maxNodesPerTick)` each tick; returns `'pending'`, `'success'`, or `'unreachable'`.
  - Once complete, `search.path` contains the coordinates.
- **World adapter:** `WorldAdapter(world, classifier?)` wraps the game `World` object. Call `adapter.invalidate()` or bump `adapter.version` when blocks change to invalidate cached paths.
- **Door predicate:** Pass `isDoorPassable(x, y, z, stateId)` to `DefaultBlockClassifier` or register a predicate to allow specific entities (e.g. Hollow breaking doors or player opening doors) to traverse door blocks.
