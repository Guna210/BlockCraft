## Notes for dependent tasks

- Each chest block entity stores `{ slots: Array<27 of { id, count } | null }` as plain JSON. A double chest is a left-to-right UI view over two block entities; M17a can serialize each state unchanged.
- Workbench and chest block/item registration is data-driven. `buildIconSheet` creates their icons from the registered block textures.
- A blocked chest break leaves its block and contents intact if the bounded item-entity pool cannot hold every occupied slot.
