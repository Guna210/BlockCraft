- Built `tests/unit/texture-resolve.test.ts` to verify texture references are fully resolvable or properly caught by the sentinel tracker.
- Added debug API `look()` in `src/debug/api/camera.ts` to update yaw and pitch from tests without moving the mouse. (Note for next task: M06a will re-point this to the player).
