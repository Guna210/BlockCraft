## What was built

- `src/render/scene-materials.ts`: Created material mapping table for 25 cube types in the test scene specifying top, side, and bottom face textures, plus cutout and transparency flags.
- `src/render/texture-resolve.ts`: Created `resolveTexture` helper and `createSentinelTile` missing texture sentinel (16×16 magenta/black 2×2 checkerboard). Added `missingTextures` tracking to `renderStats`.
- `src/render/test-scene.ts`: Built `TestScene` renderer that generates the texture atlas including sentinel tile, uploads hand-built mipmap levels 0–2 via `texImage2D` with `NEAREST_MIPMAP_LINEAR` filtering and `TEXTURE_MAX_LEVEL = 2`, constructs 5×5 cube grid mesh geometry with per-face UV mappings, and renders in three passes (opaque, cutout with alpha discard, translucent with alpha blending).
- `src/debug/api/camera.ts`: Implemented `look(yaw, pitch)` debug API driving the free-fly camera, registered in `src/debug/api/index.ts`.
- `src/main.ts`: Wired `TestScene` and `InputEngine` with minimal diff, setting default camera position looking down at 30–45° onto the 5×5 grid.
- `tests/unit/texture-resolve.test.ts`: Added unit tests verifying every material in `SCENE_MATERIALS` and every generator key resolves to a valid atlas rect, and unknown names resolve to sentinel and log into `missingTextures`.
- `tests/e2e/m01.spec.ts`: Added E2E test verifying non-blank screenshot, zero missing textures, color variance >= 18, and camera 90° rotation producing `diffFraction > 0.3`.
