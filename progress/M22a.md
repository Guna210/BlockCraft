## Implementation

- The mesh worker computes each section's 15-bit face-connectivity mask, including compact masks for sections whose geometry can be skipped. Renderer-owned storage retains and invalidates masks outside `World` and `Player`.
- Cave traversal uses flat typed arrays, a preallocated `Int32Array` queue, generation-stamped visits, frustum filtering, monotonic paths, and open masks for sections whose mesh is not ready. The last RD8 flight measured **1.1 ms BFS p95** and skips recomputation when camera section, direction bucket, and mesh masks are unchanged.
- Section frustum tests refine M04a column culling. Debug culling controls are registered only in the debug API.
- Opaque, cutout, and translucent geometry uses per-pass arena pages with column-owned allocations and release. `WEBGL_multi_draw` is used when available; the fallback draws sections individually. Per-section represented draw counts remain separate from actual GL submission counts. `?debug=1&glcheck=draw` forces the per-section path for draw attribution.
- Arena-backed geometry readback serves the debug inspection path without looking for removed per-column GPU buffers.
- Translucent ordering, fade-in, fluid, foliage, portal, remote terrain, and remote player/name-tag rendering paths are retained.
