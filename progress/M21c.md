## Acceptance criteria owned

- [ ] Two browser players see each other and block edits propagate within 500 ms.
- [ ] At 150 ms latency, movement responds within one frame and fewer than five corrections occur over a 30-second walk.
- [ ] A 20-block break is rejected and the block remains for both clients.
- [ ] Chat from one player appears for the other.
- [ ] Server termination shows the disconnect screen for both clients without uncaught errors.

## Known limitations

- No remote world, player prediction, entity interpolation, player list, chat integration, network stats or disconnect screen. The five owned E2E criteria and screenshot remain outstanding.
- The current connection discards server gameplay messages after handshake; it must be changed to deliver the initial ServerHello and subsequent messages in order before implementing remote world startup. The form's Connected state is an interim connection diagnostic, not a playable session.
- The required `--with-deps` Playwright installation failed because root authentication was unavailable. Bundled Chromium installed separately under `/tmp/m21c-browsers` and launched for the focused browser tests.
