## What was built

- Fluid-state lookup tables and individual sloped quads from shared four-cell corner heights, including padded section boundaries. Same-fluid faces are hidden for water and lava at all levels. Lava remains opaque and retains registry emission 15.
- Original dark blue water texture with sparse thin ripple crests, replacing the old bright noise thresholds. All 32 water and lava frames cycle at runtime; flow UVs move downhill and down side faces.
- Shared world-coordinate water vertex waves (maximum displacement 0.018 blocks), grazing-angle Fresnel sky tint and exponential depth absorption from an explicit depth-only opaque/cutout pre-pass. Depth resources are allocated only when translucent geometry is visible and recreated on viewport resize.
- Translucent section sorting, with quad sorting only within 48 blocks, a 0.5-block camera-motion threshold and private index buffers only for translucent buckets. Lighting program selection preserves blend order. Opaque/cutout geometry keeps shared index buffers. The renderer's resource cleanup frees private buffers and the depth target.
- `src/debug/api/fluids.ts` registers `setFluidAnimationPaused(boolean)` and `getFluidAnimation()`. Pausing simulation alone does not stop visual animation; the independent hook freezes and resumes all fluid visual motion without changing simulation state.

Changes outside new fluid modules are necessary integration: `greedy.ts` dispatches state-based fluid meshing; `vertex.ts` decodes the fluid payload; `chunk-renderer.ts` provides animation, shading, depth and ordered translucent draws; `debug/api/core.ts` and `index.ts` type/register the new domain. Worker transfers, streaming, block states/IDs, generation, physics and underwater tint/fog modules are unchanged. No existing test or verification harness file is edited.

## Known limitations

- Absorption estimates the optical path from the water fragment to the opaque depth along the view ray. It is a depth approximation, not multi-layer fluid-volume integration. Reflection is a sky tint; no reflected scene or refraction is introduced.
- The explicit depth pre-pass adds opaque/cutout submissions only in frames with visible translucent geometry. Sorting and private index storage apply only to translucent sections.
- The existing full-block fluid occupancy/underwater detection remains unchanged; this task changes rendered surface heights, not swimming physics or the underwater effect.
- Publication and GitHub CI Verify await the owner's first-push approval. Local evidence is not represented as PR CI evidence.

## Notes for dependent tasks

M08a states remain enum strings: `level: '0'`–`'7'`, `falling: 'false' | 'true'`. The eight-byte vertex stride is unchanged. Fluid material tags 4/5 reserve word-1 bits 12–21 and 30–31 for surface depression, flow and logical unit UVs; non-fluid vertex formats retain their old interpretation. `decodeVertex` returns actual heights and logical UVs. M08c's translucent blocks use the same ordered renderer without needing fluid material tags. The transparent depth target is disposed by `clearAllMeshes`; per-section sorting buffers are disposed on ordinary section eviction.
