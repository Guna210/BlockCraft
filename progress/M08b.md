## What was built

- Fluid-state lookup tables and individual sloped quads from shared four-cell corner heights, including padded section boundaries. Same-fluid faces are hidden for water and lava at all levels. Lava remains opaque and retains registry emission 15.
- Original dark blue procedural water with sparse thin ripple crests, replacing the old bright noise thresholds. All 32 water and lava frames cycle at eight frames per second; flow UVs move downhill and down side faces.
- Shared world-coordinate water vertex waves (maximum displacement 0.018 blocks), grazing-angle Fresnel sky tint and exponential depth absorption from completed opaque/cutout/player depth, resolved before translucent draws. The depth target is allocated only with visible translucent geometry and resized with the viewport; world geometry is submitted once.
- Translucent section sorting, with quad sorting only within 48 blocks, a 0.5-block camera-motion threshold and private index buffers only for translucent buckets. Lighting program selection preserves blend order. Opaque/cutout geometry keeps shared index buffers. Center decoding avoids full vertex-object allocations; sorting computes distances once and fills indices without per-quad arrays. Camera movement reuses section membership until meshes change. Resource cleanup frees private buffers and the depth target.
- `src/debug/api/fluids.ts` registers `setFluidAnimationPaused(boolean)` and `getFluidAnimation()`. Pausing simulation alone does not stop visual animation; the independent hook freezes and resumes fluid visual motion without changing simulation state.

Integration changes: `greedy.ts` dispatches state-based fluid meshing; `vertex.ts` shares position decoding and decodes the fluid payload; `chunk-renderer.ts` provides animation, shading, depth and ordered translucent draws; `debug/api/core.ts` and `index.ts` type/register the new domain; `main.ts` requests stencil so the default packed depth format can be matched for resolving. Streaming, worker transfers, generation and physics are unchanged by M08b. Underwater tint/fog modules are unchanged.

The owner explicitly approved adding the pause hook to the two existing M02c static-image tests. Every assertion and both 1% thresholds remain unchanged. No other existing test or verification harness file is edited by M08b.

## Known limitations

- Absorption estimates the optical path from water to opaque depth along the view ray, rather than integrating multiple fluid volumes. Reflection is a sky tint; no reflected scene or refraction is introduced.
- A viewport-sized depth resolve runs with visible translucent geometry. Sorting and private index storage apply only to translucent sections.
- Existing full-block fluid occupancy/underwater detection is retained; rendered fractional heights do not change swimming physics.
- Local full verification exits 1 only on the two owner-listed container cases above. Publication and GitHub CI await first-push approval, so this record does not claim the repository's verified definition of done yet.

## Notes for dependent tasks

M08a states remain enum strings: `level: '0'`–`'7'`, `falling: 'false' | 'true'`. The eight-byte vertex stride is unchanged. Fluid material tags 4/5 reserve word-1 bits 12–21 and 30–31 for surface depression, flow and logical unit UVs; non-fluid formats keep their old interpretation. `decodeVertex` returns actual heights and logical UVs. Other translucent blocks, including weather's ice, use the ordered renderer without fluid tags. The depth target is disposed by `clearAllMeshes`; per-section sorting buffers are freed on ordinary section eviction.
