## Pipeline Interface Contract (for M03c–M03f)

The terrain pipeline lives in `src/gen/pipeline.ts`. Pipeline stages append to `TerrainPipeline` and execute sequentially for each column:

```ts
export type TerrainStageFunction = (
  stageSeed: number,
  cx: number,
  cz: number,
  column: ChunkColumn,
) => void;

export interface TerrainStage {
  name: string;
  generate: TerrainStageFunction;
}
```

- Each stage is a pure function of `(stageSeed, cx, cz, column)`. Stage implementations cache noise closures per stage seed to eliminate per-call sampler allocations.
- Per-stage seeds are derived deterministically using `deriveSeed(worldSeed, stage.name)` from `src/engine/rng.ts`.
- Results never depend on generation order, worker assignment, or timing.
- M03b's terrain is composed strictly of `stone`, `water`, `foundation_stone`, and `air`. Surface blocks (grass, sand, etc.) belong to M03c.

## Measured Generation Performance

- Real per-section worker generation time (`getWorkerStats().genMsP95`): **~0.15–0.28 ms / 16³ section** (column generation ~1.5–2.8 ms for 10 active sections; well within the ≤ 6 ms budget enforced in M04a). Fast evaluation achieved by density bounds skipping (`|targetH - y| > 24`).
