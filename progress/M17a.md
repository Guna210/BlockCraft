## What was built

- **Compression (`src/persist/compress.ts`)**:
  - `deflate(data: Uint8Array): Promise<Uint8Array>` and `inflate(data: Uint8Array): Promise<Uint8Array>` using native browser/Node `CompressionStream('deflate')` and `DecompressionStream('deflate')`.
- **Versioning & Migration Registry (`src/persist/version.ts`)**:
  - Exported `FORMAT_VERSION = 1` and `migrations` (`MigrationRegistry`).
  - Supports registering domain migrations (`migrations.registerColumn(fromVersion, fn)` and `migrations.registerWorld(fromVersion, fn)`).
  - Validates versions on deserialization and migrates sequentially.
- **Binary Column Format (`src/persist/column-format.ts`)**:
  - Magic bytes: `0x42, 0x43, 0x43, 0x46` (`'BCCF'`).
  - Fixed 1807-byte header: magic (4), format version (2, uint16), `cx` (4, int32), `cz` (4, int32), section count (1, uint8 = 20), biome indices (256 bytes), grass tints (768 bytes, 256×3), and foliage tints (768 bytes, 256×3). Preserves smooth cross-chunk color blending without requiring re-sampling.
  - Per-section encoding:
    - `paletteSize === 0`: Unallocated section (implicit air).
    - `paletteSize === 1`: Uniform section (stores 2 bytes `uniformStateId`).
    - `paletteSize > 1`: Palette array of `uint16` state IDs + bit-packed index array (1/2/4/8/16 bits per entry matching `src/world/chunk.ts`).
  - Strict validation:
    - Rejects unknown state IDs against `BlockRegistry`.
    - Throws clear error on out-of-range packed indices (`pIdx >= paletteSize`).
    - Throws clear error on trailing unparsed bytes after the 20 sections.
  - Recomputes lighting on load via `LightEngine` rather than serializing sky/block light arrays, saving ~40 KB per column.
  - Async APIs `serializeColumn()` and `deserializeColumn()`, plus synchronous binary helpers `serializeColumnBinary()` and `deserializeColumnBinary()`.
- **Specialized Serializers (`src/persist/serializers.ts`)**:
  - Block entities: `serializeBlockEntities`, `deserializeBlockEntities` with plain-JSON validation via `isPlainJsonObject`.
  - Inventory: `serializeInventory`, `deserializeInventory` supporting all 41 slots (hotbar 0..8, main 9..35, armor 36..39, offhand 40), cursor stack, unstackables with count 1, and `selectedSlot` (0..8). Validates armor slot placement constraints and passes `Inventory.assertInvariant()`.
  - Item entities: `serializeItemEntities`, `deserializeItemEntities` for ground drops (`id, count, position, velocity, pickupDelay, age`).
  - Player data: `serializePlayerData`, `deserializePlayerData`, `applyPlayerData` for full player fields (`position, rotation, mode, selectedSlot, health, hunger, saturation, air, flying, dimension`).
  - World metadata: `serializeWorldMetadata`, `deserializeWorldMetadata` for `seed, timeOfDay, weather, manualOverride, strikeCounter, lastTick, elapsed, breakCount, worldType`. Fully synchronizes with `weatherManager` state.
  - Scheduled block ticks: `serializeBlockTicks`, `deserializeBlockTicks`, `serializeColumnTicks` supporting `BlockTicks` and column-filtered ticks (`time` and list of `ScheduledTick` with `x, y, z, type, due, priority, order`). Preserves mid-flow fluids across world save/reload.
  - Unified World container: `serializeWorld` and `deserializeWorld` packing columns, block entities, inventory, item entities, player data, world metadata, and scheduled block ticks into ONE self-describing Uint8Array (`WORLD_MAGIC = 0x44574342`, `'BCWD'`). Header is 34 bytes with 7 table-of-contents length entries. Full bounds-checking throws clear "truncated world data" errors on truncated buffers.
- **World & BlockTicks Extensions (`src/world/ticks.ts`, `src/world/world.ts`)**:
  - `BlockTicks`: Added `getPendingTicks()`, `getPendingTicksForColumn(cx, cz)`, `loadTicks(ticks, time, replace)`, and `addTicks(ticks)` for snapshotting, restoring, and merging pending queues.
  - `World`: Added `setColumn(col)` to directly adopt deserialized chunk columns.
- **Module Index (`src/persist/index.ts`)**:
  - Re-exports all serialization and persistence APIs.

## Compression Sizes

- **All-air column**: 40 bytes (compressed with deflate).
- **Typical pipeline-generated column** (generated via `createDefaultPipeline().generateColumn` covering terrain, surface rules, biomes, foliage/grass tints, caves, ores, features): 1165 bytes (compressed with deflate).

## Notes for dependent tasks

- **Column Serialization (`src/persist/column-format.ts`)**:
  - `serializeColumn(col: ChunkColumn): Promise<Uint8Array>` produces compressed column bytes including grass and foliage tints.
  - `deserializeColumn(bytes: Uint8Array): Promise<ChunkColumn>` restores column coordinates, biomes, tints, section palettes, and block states.
- **Unified World Container (`src/persist/serializers.ts`)**:
  - `serializeWorld(data: WorldSaveData): Promise<Uint8Array>` packs modified columns, block entities, item entities, inventory, player data, world metadata, and scheduled block ticks into a single `.save` buffer.
  - `deserializeWorld(bytes: Uint8Array): Promise<WorldSaveData>` unpacks all components with format version verification and bounds checking.
- **Scheduled Block Ticks (`src/persist/serializers.ts`, `src/world/ticks.ts`)**:
  - `serializeBlockTicks(ticks)` and `deserializeBlockTicks(bytes)` preserve pending fluid updates and block ticks across sessions.
  - `world.ticks.loadTicks(data.ticks, data.time)` restores pending ticks into the simulation.
- **Migration Registry (`src/persist/version.ts`)**:
  - `migrations.registerColumn(fromVersion, fn)` and `migrations.registerWorld(fromVersion, fn)` provide version bump hooks for future format versions.
