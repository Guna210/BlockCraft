## What was built

- **World time & sky-light curve (`src/world/time.ts`, `src/engine/loop.ts`):**
  - `worldTime` in ticks (`TICKS_PER_DAY = 24000`, `TIME_SUNRISE = 0`, `TIME_NOON = 6000`, `TIME_SUNSET = 12000`, `TIME_MIDNIGHT = 18000`), starting at `6000` (noon) on new worlds (`resetWorldTime()`).
  - Single `advance(ticks)` entry point called with `1` on each simulation tick in `TickLoop` (`src/engine/loop.ts`), so both real-time simulation and paused `window.__blockcraft.tick(n)` advance `worldTime`.
  - Smooth cosine-eased `skyLightMultiplier(ticks)` (`1.0` during daytime, `0.2` at night, max tick-to-tick delta `~0.0006283183 << 0.05`) driving `ChunkRenderer`'s `u_skyBrightness` uniform every frame without re-meshing.
  - `sunDirection(ticks)` and `moonDirection(ticks)` on a `15°`-tilted orbit (`East = +X` at `yaw = 0`, `West = -X` at `yaw = Math.PI`), plus `moonPhase(ticks) = ((Math.floor(ticks / 24000) % 8) + 8) % 8`.
- **Debug API (`src/debug/api/time.ts`, `src/debug/api/core.ts`, `src/debug/api/index.ts`):**
  - Added `window.__blockcraft.setTimeOfDay(ticks: number)` per SPEC §4, registered via a single `import './time';` line in `src/debug/api/index.ts`. Triggers an immediate world re-render so screenshots after `setTimeOfDay` reflect the new sky and `u_skyBrightness` immediately.
- **Procedural sun & moon textures (`src/render/textures/sky.ts`, `src/render/textures/index.ts`):**
  - Added `genSun` (`sun`) and `genMoon0`..`genMoon7` (`moon_0`..`moon_7`) 16×16 procedural textures and palettes (`PAL_SUN`, `PAL_MOON`) following `ART.md` (≤ 12 colours per tile, deterministic PRNG).
- **Full-screen sky pass & sun/moon billboards (`src/render/sky.ts`, `src/world/world-manager.ts`):**
  - `SkyRenderer` renders first each frame with depth writes disabled (`gl.depthMask(false)`):
    1. A full-screen triangle computing the zenith-to-horizon day/night sky gradient, directional sunrise/sunset horizon glow (`GLSL_SKY_ATMOSPHERE`), and a 3D hashed direction-grid starfield with per-cell twinkle that fades in at dusk.
    2. Textured billboard quads for the sun (`sun` tile) and moon (`moon_0`..`moon_7` selected by `moonPhase(worldTime)`), faded near the horizon.
- **Distance fog (`src/render/chunk-renderer.ts`):**
  - Added linear distance fog between `0.75 * renderDistance * 16` (`u_fogStart`) and `1.0 * renderDistance * 16` (`u_fogEnd`), evaluated per vertex against `skyAtmosphereColor` in the view direction (`skyCol * 0.95`) so distant chunks blend smoothly into the horizon at all times of day while preserving M04 horizon coverage checks.
- **Noon sky classifier update (`tests/e2e/helpers/sky-holes.ts`, `tests/unit/sky-holes.test.ts`):**
  - Per Decision 7, updated `isSkyPixel` to recognise both the legacy flat clear colour `(102, 204, 255)` (Euclidean RGB radius 16) and the new M12a noon sky gradient band (`68 <= r <= 138, 164 <= g <= 216, b >= 245, b - r >= 110`), while rejecting the fully fogged sky contribution (`b <= 242`). Review found that partially fogged terrain and unfogged packed ice can still match this band; M12a-fix addresses that finding.
