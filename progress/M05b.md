## What was built

Worker-side rectangular lighting and exact light skirts, independently propagated RGB, smooth corner samples, strict sky/R/G/B/AO merge tuples and AO diagonal selection, two-word shared vertex decoding, vertex-stage brightness/tint/AO shading, day multiplier and debug fullbright, and an original procedural standing torch. Generation/light/mesh use separate real worker pools at the SPEC/master default max(2, hardwareConcurrency − 1). Workers build voxel/light padding from transferred compact neighbour snapshots; generation now transfers existing packed chunk storage instead of rebuilding it voxel by voxel on the main thread. Quad indices are shared; vertex records stay 8 bytes.

The follow-up bounds stage dispatch with a shared 3 ms deadline, copies light inputs in 1 ms section slices, frees one GPU section per streaming step, prioritizes the nearest 16 moving columns' generation-border→light→mesh chains, starts singleton light batches immediately, finishes near-column uploads first under the existing 3 ms budget, and releases the focus restriction when stationary so all queues drain. The frame callback is synchronous; native worker messages deliver between callbacks, and streaming/upload work precedes drawing without an unconditional message turn or promise suspension. No draw is gated, skipped or deferred and no merge/test threshold is changed.
