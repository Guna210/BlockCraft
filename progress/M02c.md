## What was built

- `src/gen/flat.ts`: Small self-contained flat world generator (stone to y=60, dirt to y=63, grass_block at y=64, air above y=64) measuring generation time per region to populate `genMsP95`.
- `src/workers/mesh.worker.ts`: Vite module Web Worker executing `greedyMesh` on transferable 18x18x18 `Uint16Array` padded section buffers and returning typed array bucket vertex/index buffers as transferables.
- `src/mesh/worker-pool.ts`: Worker pool sized `max(2, navigator.hardwareConcurrency - 1)` dispatching mesh jobs, tracking live `queueLength`, and measuring `meshMsP95` (p95 of time `greedyMesh` takes inside the worker). Surfacing worker errors as uncaught errors/rejected promises.
- `src/render/chunk-renderer.ts`: GLSL ES 3.00 terrain renderer decoding M02b 2xuint32 packed layout with `vertexAttribIPointer`, `u_sectionOrigin`, and grid arithmetic deriving tile rects from `v_tileIndex` without uniform array limits. `textureGrad` sampling with unwrapped UV derivatives and clamped tile coordinates to prevent border/mip bleeding. Separate opaque, cutout (alpha-test discard), and translucent (blended, depth write off) passes.
- `src/debug/api/wireframe.ts`: Wireframe debug API module registered in `src/debug/api/index.ts` drawing quad edges as black lines.
- `src/world/world-manager.ts`: Manages world flow (`createWorld`, `waitForTerrain`, `getWorkerStats`). `createWorld` replaces the `World` instance via `setWorldInstance()`, positions free-fly camera at spawn y=80 looking at horizon, and enqueues sections for worker meshing and GPU upload. `waitForTerrain(r)` resolves once every column within radius `r` is generated, meshed, and uploaded.
- `tests/e2e/m02.spec.ts` & `tests/unit/flat.test.ts` & `tests/unit/worker-pool.test.ts`: Extended E2E specs and unit tests covering flat world generation, camera position, sky/grass hue assertions, `meshMsP95 ≤ 6`, `m02-flat.png`, and `m02-wireframe.png`.

## Decisions (links to decisions/ files)

- **Tile Rect Derivation:** In `src/render/chunk-renderer.ts`, derived tile rects directly from `v_tileIndex` using regular grid arithmetic in GLSL (`col = tileIndex % cellsPerRow`, `row = tileIndex / cellsPerRow`, `tilePos = vec2(col * 24 + 4, row * 24 + 4)`). This avoids WebGL uniform vector limits when adding future tiles and requires zero data textures.

## Notes for dependent tasks

- **World Flow & Debug API:**
  - `createWorld(opts)` generates a flat world by default, sets the global world instance with `setWorldInstance()`, positions the free-fly camera at y=80 looking at the horizon, and initiates worker meshing.
  - `waitForTerrain(radiusChunks)` resolves when all columns within radius `radiusChunks` are generated, meshed in workers, and uploaded to WebGL buffers.
  - `getWorkerStats()` returns `{ genMsP95, meshMsP95, queueLength }`.
- **Streaming (M04a):**
  - M02c loads radius 4 columns directly via `createWorld` and `waitForTerrain`. M04a will build the dynamic spiral streaming system around player position.
