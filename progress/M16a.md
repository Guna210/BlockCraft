## What was built
- Implemented `SynthesisEngine` in `src/audio/engine.ts` using web audio primitives (oscillators, filtered noise, simple ADSR-style envelopes) for generative sound synthesis without external files.
- Added `LCG` in `src/audio/math.ts` for deterministic random number generation to ensure offline rendering consistency.
- Defined audio recipes under `src/audio/recipes/*` mapping strings like `footstep.grass` or `creature.hollow.death` to procedural synthesis code.
- Exposed a debugging API at `window.__blockcraft.audio.renderOffline` (available with `?debug=1`) to offline render any given sound ID.
- Wrote Playwright E2E spec `tests/e2e/m16a.spec.ts` asserting every required sound ID exists, renders deterministically, and satisfies the RMS/Peak criteria (RMS > 0.01, Peak < 0.8).

## Creature Voices
- **Tuftbuck**: Mid-pitch sawtooth bleats with quick pitch bends.
- **Rootboar**: Low, rumbling square wave grunts dropping in pitch.
- **Dapplefowl**: High, short triangle wave clucks and squawks.
- **Mossback**: Very slow, deep, and resonant sine wave groans.
- **Glimmer Moth**: Tiny, very high-pitched (2kHz+) sine wave chirps.
- **Hollow**: Raspy, airy breathing built from heavily filtered noise and sawtooth.
- **Thornling**: Woody creaks and sharp square-wave clicks.
- **Skitterer**: Fast, high-frequency (1.2kHz+) triangle wave chittering.
- **Sporeburst**: Squishy, bubbly swelling sine wave sounds that rise in pitch.
- **Glowwing**: Ethereal, sweeping hums around 600Hz.
- **Magmaw**: Bubbling, resonant deep bass using a 50Hz square wave.
