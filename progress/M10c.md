## What was built

1. **Kiln block definition (`data/blocks/kiln.json`) & assets**:
   - Hardness 3.5, blast resistance 3.5, required tool `pickaxe`, `minTier: 0`.
   - States: `facing` (`north`, `south`, `east`, `west`) and `lit` (`false`, `true`).
   - Data-driven lighting: `"lightEmissionWhen": { "lit": "true", "value": 13 }` emitting light 13 only when lit.
   - Textures: `front`, `front_lit`, `top`, `side`, and `bottom` using procedural generators in `src/render/textures/kiln.ts`.
   - Item definition `data/items/kiln.json`, loot definition `data/loot/kiln.json` (self-drop), recipe `data/recipes/kiln.json` (8 cobblestone ring).
   - Block break spilling: `spillKilnContents` (src/gameplay/kiln.ts) runs from M10b's `onBreakBeforeRemove` hook, next to chest spilling; a full item pool refuses the break.
2. **State IDs (`data/block-state-ids.json`)**:
   - Master's entries are kept exactly (they end at 533, after M10b's workbench/chest and BLOCKS-shapes' stairs/fences/doors/trapdoors).
   - Appended the 8 kiln states at IDs `534..541` (`kiln[facing=east,lit=false]` = 534 … `kiln[facing=west,lit=true]` = 541).
   - `tests/unit/m08c-glass-foliage.test.ts` is master's version, unmodified.
3. **Core Decoupling & Kiln block entity (`src/gameplay/kiln.ts`, `src/world/block-entities.ts`, `src/main.ts`)**:
   - Decoupled `src/world/block-entities.ts` by removing kiln import and registration.
   - Runtime startup registration in `src/main.ts` via `registerKilnBlockEntity()`.
   - Registered through M10a's `blockEntityRegistry` (`blockEntities.register`) as plain JSON for M17a compatibility.
   - Tracks `input`, `fuel`, `output`, `burnRemaining`, `burnTotal`, `cookProgress`, and `storedXp`.
   - Cook speed: 200 ticks (10 seconds) per smelted item.
   - Fuel burn times sourced via `getBurnTime(itemId)` in `src/gameplay/smelting.ts`.
   - Lit state updates block state ID dynamically and continues ticking in loaded chunks.
4. **Data-driven block rendering & lighting**:
   - `src/world/blocks/registry.ts`: Generic facing and lit texture resolution for blocks defining `front` (and `front_lit`). Zero references to `'kiln'`.
   - `src/ui/icons.ts`: Generic south face resolution for blocks defining `front` / `front_lit`. Zero references to `'kiln'`.
   - `src/world/lighting.ts`: Data-driven `lightEmissionWhen` condition matching. Zero references to `'kiln'`.
5. **Experience points (XP) (`src/gameplay/xp.ts`)**:
   - Original 3-tier piecewise linear curve in `pointsForLevel(level)`: 10 + 2*L for L<15, 40 + 5*(L-15) for L<30, 115 + 10*(L-30).
   - `addXp(player, points)` awards XP points and advances `player.xpLevel` and `player.xpProgress`.
   - Kiln stores XP per smelt and disburses it when output is collected.
6. **Kiln screen UI & Flame Redesign (`src/ui/kiln-screen.ts`, `src/ui/kiln-layout.ts`)**:
   - 39-slot UI panel with input, fuel, output slots, 27 inventory slots, and 9 hotbar slots.
   - Ragged teardrop flame: outer RED (`#b32b1b`), ORANGE body (`#d96d1a`) and a small YELLOW teardrop core (`#f2c12e`).
   - 3 animation frames move the tip and 1–2 small flickering tongues on the outer edge while burning.
   - Shrinks smoothly from top down as fuel is depleted.
   - Renders empty dark outline (`UI.outline` edge, `UI.slot` interior) when unlit or depleted.
   - Animated horizontal progress arrow indicating cook progress (`cookProgress / 200`).
   - Shift-click routing: fuel items to fuel slot, smeltables to input slot, output items to inventory with XP collection.
7. **Tool wear and durability (`src/gameplay/inventory.ts`, `src/persist/serializers.ts`, `src/ui/ui-kit.ts`)**:
   - Survival block breaks deduct 1 durability point (`damage` incremented by 1).
   - Tool breaks at max durability (`getToolDurability(itemId)`), removing tool and emitting break particles.
   - Stored as `damage` on `ItemStack` with serialization round-trip support.
   - Rendered durability bar (`drawDurabilityBar`) on damaged items in UI slots.
8. **Harvest level gating (`src/engine/player-controller.ts`, `src/gameplay/mining.ts`)**:
   - Blocks broken with inadequate tool tier or wrong tool type drop nothing.

## Notes for dependent tasks

- **Kiln UI & Interaction**: Kiln opens through M10b's `onUse` hook (`playerController.onUseBlock` in `main.ts`, which calls `UiManager.openKiln`). The UI is screen `'kiln'` in `UiManager`; `openScreen('kiln')` opens the nearest kiln within reach.
- **Tool Durability**: Access tool damage via `stack.damage ?? 0`. Tools break when `stack.damage >= getToolDurability(stack.id)`.
- **XP API**: Use `addXp(player, points)` from `src/gameplay/xp.ts` for awarding player XP.
