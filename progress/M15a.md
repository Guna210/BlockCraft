## Notes for dependent tasks

- Main simulation API: `world.current`; implementation and state helpers are in `src/gameplay/current/`.
- Component face directions are north/east/south/west. Relay and Gauge face toward their output; input is behind, while Relay lock and Gauge side input sample the horizontal sides.
- Trace power is `state.power`; trace mesh connectivity is derived from neighboring blocks and has no block-state fields.
- Buttons use `world.current.useBlock(x, y, z)` and `BlockTicks`; stone releases at 20 ticks and wood at 30.
- Add entity providers through `world.entityQuery.addProvider(id, provider)`. Provider IDs are queried in sorted order and returned entities are AABB-filtered.
- Container block entities expose `container(entity)` in their `BlockEntityTypeDefinition`; use `world.blockEntities.getContainer(x, y, z)` to read slots.
- State IDs 542–698 are allocated to M15a; preserve them when later task states are added.
