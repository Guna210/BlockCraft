## What was built

The single Playwright scenario in `tests/e2e/m23-playthrough.spec.ts` drives the ten M23 steps with player input and the public UI. It asserts inventory and block changes through the debug API and compares the saved circuit and inventory after a page reload.

The sleep handler in [src/main.ts:262](../src/main.ts#L262) advanced the clock while leaving the player at the interaction point. It now resolves the bed's safe position and moves the player during the fade. Step 8 compares the actual wake position to the bed location.

The inventory mouse handler in [src/ui/ui-manager.ts:1686](../src/ui/ui-manager.ts#L1686) treated a fast return to the source slot as a double-click after an intervening crafting-grid click. The handler now requires consecutive left clicks on the same slot. The M23 crafting checks verify that unused ingredients return to the source and clear the cursor. The [Workbench layout](../src/ui/ui-manager.ts#L1179) also registered each visible storage hitbox twice, so the UI could interpret a storage click as a crafting-grid action. Storage hitboxes now use the correct slot IDs on their first registration, and M23 checks the ingredient on the cursor after each pickup.
