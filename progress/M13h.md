## Notes for dependent tasks

- Spawn id: `cinderwraith`; dropped item id: `cinder_shard`.
- Set `ModelPart.emissive` for selectively glowing parts. `EntityModel.emissive` retains its prior whole-model semantics. The baked vertex stride is exported as `ENTITY_VERTEX_FLOATS`; consumers should use it rather than hardcode a stride.
- Cinder-specific targeting updates during goal selection, before melee continuation is checked. This lets calming stop navigation immediately without leaving melee with a vanished target.
- Gaze scratch is allocated only when a Cinderwraith's goals are first built. Per-type particles run through its definition tick, so worlds without Cinderwraiths emit none and install no Cinderwraith system.
- Teleport resets position interpolation, velocity and navigation; paths never interpolate across the jump. Landings are centered in a loaded column's air cell above full solid support.
