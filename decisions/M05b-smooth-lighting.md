# M05b — Smooth lighting and AO decisions

All decisions below were supplied by the owner. The later approval permits decoder-only changes in the two legacy unit files, with no assertion changes.

1. Streamed light is computed from a ready rectangle plus a full column border, committing only the interior. A one-block skirt supplies exact light when a neighbour is unlit. Light completion never remeshes neighbours. Stages are generated → lit → meshed; the light and mesh rings coincide. Generation/free rings remain unchanged. Per-cell work runs in workers, above-height sections share a sky sentinel, opaque non-emitting sections are zero, and light is freed with columns. Edits retain incremental BFS restricted to lit columns. The createWorld region barrier remains; a unit test compares it cell for cell with batched lighting.
2. RGB propagates/removes independently and combines by channel max. The scalar block-light cache remains equal to the RGB maximum. Tint uses rounded inverse-brightness offsets, tested per emitter. Torch emits 14 with pale warm RGB proportions (1, 0.8, 0.55); lumite ore emits its existing 12 in cool cyan; lava emits 15 in orange-red. No lamp or glowcap placeholders.
3. Revision of `M02b-vertex-format.md`: word 0 remains x/y/z (5 bits each), normal (3), AO (2), sky (4), block R (4), tint (4). Word 1 is tile index bits 0–11, u bits 12–16, v bits 17–21, block G bits 22–25, block B bits 26–29, spare bits 30–31. Source, shader and test decoding share constants. An atlas-size test fails at 4096 tiles.
4. Each corner averages the non-opaque outward face/side/side/corner samples, dropping the corner when both side samples are opaque. AO is 3 when both sides are opaque, otherwise the sum of side and corner occlusion. Diagonals compare corner light/AO scores and are symmetry-tested. Greedy merging requires identical sky/R/G/B/AO tuples at all four corners and across merged faces. Plants/models use own-cell light without AO; water uses smooth light without AO. Below-world padded light is zero.
5. Light interpolates before the fragment brightness curve `b(L) = 0.04 + 0.96 L/15`. Named constants also define AO, with AO zero equal to one. Texture colour multiplies the per-channel maximum of sky brightness times the day multiplier and RGB brightness, then AO and existing face shading. The day multiplier defaults to one and has a renderer setter for M12.
6. Standing torch uses an original procedural cross sprite and `data/blocks/light-sources.json`. Integer corner positions are retained. No item, icon or wall torch is introduced.
7. A separate debug API module provides `setDebugLight(on)`, off by default. It overrides brightness to one while retaining AO and face shading. The only test calls are around the two owner-named M03 cave screenshots. Other tasks' committed screenshots are restored after verification.
8. M05 visual tests use a sealed stone room and an open-roof stone inner corner. They retain the supplied dark/rise/hue/AO thresholds, record camera and room geometry, and save the two named screenshots under M05b. Unit tests cover decisions 1–4.
9. Stage counters expose completed generation, light, mesh and upload columns, queue depths and cancellation counts. Flight throughput compares master and branch at the same speed. Every stage prioritises distance; light jobs are bounded independently and preserve generation/mesh worker capacity. A stale column is rejected individually within a batch. Idle detection includes light work; adopted region light can still queue a subsequent mesh request. All M04 tests retain their assertions and thresholds.

Edits additionally refresh affected columns' worker-computed skirts. The incremental BFS remains immediate; the refresh prevents stale skirts beside unlit neighbours and rejects an in-flight snapshot invalidated by a later edit. An unlit border edit also invalidates nearby snapshots that read that border, even though the guarded incremental BFS has no touched sections there. A deduplicated column set preserves per-column rejection rather than cancelling the batch.

The initial region computes from the generated outer ring but commits only its interior, so later outer-ring meshes obtain an exact skirt from their ready border. Ready streaming strips may run along X or Z. Waiting uploads are re-prioritised along with mesh work, and draining upload backpressure resumes mesh dispatch immediately.

For rendering cost, the worker labels meshes whose RGB components are all zero. Those use an algebraically identical sky-only fragment formula, including the minimum brightness of the zero block-light channels. Other meshes use the full RGB formula. Quad normals use flat interpolation; sky/RGB/AO still interpolate. Sampling reads the shared nine-cell face stencil once, with byte-separated channels for safe four-sample sums.

The debug-light setter presents a frame synchronously, so fullbright also takes effect while a caller holds the normal animation loop. Debug wireframe outline buffers are created on first use, rather than alongside every terrain upload; their contents and mesh lifetime remain unchanged.
